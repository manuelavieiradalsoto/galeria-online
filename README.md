# 🎨 Galeria Online — Loja Virtual de Desenhos e Pinturas

Projeto acadêmico e pessoal de **Análise e Desenvolvimento de Sistemas (ADS)**: uma loja virtual completa para vender obras de arte originais e reproduções.

## 📌 O que é o projeto?

A **Galeria Online** é um e-commerce desenvolvido para que artistas possam vender desenhos e pinturas diretamente ao público, sem depender de marketplaces que cobram comissões elevadas e reduzem o controle sobre a identidade do artista.

O cliente poderá:

- Navegar pelo catálogo de obras com imagens de alta qualidade.
- Pesquisar por nome, técnica, tema ou artista.
- Filtrar obras por faixa de preço.
- Ordenar os resultados por menor preço, maior preço ou data de publicação.
- Conhecer a visão e o propósito da galeria em uma página dedicada, com destaque na página inicial.
- Deixar comentários e avaliações de 1 a 5 estrelas após a compra.
- Calcular o frete utilizando o CEP.
- Realizar pagamentos via Pix ou cartão.
- Acompanhar o envio de suas compras.

## 🎯 Objetivos

### Comercial

Criar um canal próprio de vendas de arte, com identidade visual autoral e uma experiência de compra segura, intuitiva e agradável.

### Acadêmico

Aplicar na prática os conhecimentos adquiridos durante o curso de ADS, incluindo:

- Engenharia de requisitos.
- Modelagem UML.
- Modelagem e gerenciamento de bancos de dados.
- Programação web.
- Testes de software.
- Gestão de projetos.
- Experiência do usuário (UX).
- Segurança da informação e Lei Geral de Proteção de Dados (LGPD).

### Profissional

Desenvolver um projeto real e completo para o portfólio, publicado na internet e versionado no GitHub.

## 💡 Por que estamos desenvolvendo?

A arte é um produto emocional e visual, e o design de uma loja virtual influencia diretamente a experiência do cliente e sua decisão de compra.

Um site próprio permite contar a história de cada obra, apresentar o processo criativo do artista e construir uma identidade visual autêntica.

Além disso, marketplaces genéricos nem sempre valorizam adequadamente o trabalho artístico, oferecem pouco controle sobre a marca e podem cobrar taxas elevadas.

O envio de obras de arte também exige cuidados especiais devido ao risco de danos durante o transporte. Uma loja própria permite explicar como cada peça será embalada e protegida, transmitindo mais confiança ao comprador.

Por fim, o projeto representa uma oportunidade de aprender e aplicar todas as etapas do desenvolvimento de software, desde a concepção da ideia até a publicação e manutenção de uma aplicação real.

## 🌍 Visão do projeto

> Aproximar pessoas da arte original, tornando cada obra acessível, compartilhando sua história e garantindo que ela seja entregue com o cuidado que merece.

## 🧱 Tecnologias principais

| Camada | Tecnologia |
|---|---|
| Design e prototipação | Figma |
| Front-end | HTML, CSS, TypeScript, React e Next.js |
| Estilização | Tailwind CSS |
| Animações | Framer Motion e CSS |
| Back-end | Next.js (rotas de servidor) e Supabase |
| Banco de dados | PostgreSQL via Supabase |
| Pagamentos | Mercado Pago (Pix e cartão) |
| Cálculo de frete | API do Melhor Envio (Correios, Jadlog etc.) |
| Hospedagem | Vercel |
| Domínio | `.com.br`, via Registro.br |
| Versionamento | Git e GitHub |

As justificativas técnicas e os detalhes da arquitetura estão disponíveis em [`docs/PLANO_DE_PROJETO.md`](docs/PLANO_DE_PROJETO.md).

## 🚦 Fases do desenvolvimento

- [ ] **Fase 0 — Preparação do ambiente:** instalação das ferramentas e configuração do ambiente de desenvolvimento.
- [ ] **Fase 1 — Concepção e requisitos:** definição do escopo, levantamento de requisitos e planejamento.
- [ ] **Fase 2 — Design no Figma:** criação dos protótipos, definição da identidade visual e planejamento da experiência do usuário.
- [ ] **Fase 3 — Fundamentos de front-end:** estudo e aplicação de HTML, CSS e TypeScript.
- [ ] **Fase 4 — Front-end com Next.js:** desenvolvimento das páginas e dos componentes da aplicação.
- [ ] **Fase 5 — Back-end, banco de dados e painel administrativo:** implementação da lógica de negócio, integração com o Supabase e gerenciamento das obras.
- [ ] **Fase 6 — Comentários e avaliações:** implementação do sistema de avaliações e comentários dos compradores.
- [ ] **Fase 7 — Carrinho, pagamento e frete:** desenvolvimento do fluxo de compra, integração com o Mercado Pago e cálculo de frete.
- [ ] **Fase 8 — Animações e polimento:** aplicação de animações, ajustes visuais e melhorias de usabilidade.
- [ ] **Fase 9 — Testes e qualidade:** validação das funcionalidades, correção de erros e verificação de segurança.
- [ ] **Fase 10 — Lançamento (deploy):** publicação da aplicação na Vercel e configuração do domínio.
- [ ] **Fase 11 — Manutenção e crescimento:** correções, melhorias contínuas e implementação de novas funcionalidades.
